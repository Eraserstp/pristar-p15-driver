# План разработки драйвера Pristar P15

Статус: итерации 0–5 выполнены, драйвер собран в .deb и проверен печатью.
Итерация 6 (надёжность) — базовые меры реализованы; итерация 7 — опционально.

## Архитектура (целевая)

```
приложение
   │  PDF
   ▼
CUPS: pdftopdf → pdftoraster
   │  application/vnd.cups-raster (203 dpi, 1/8 бит)
   ▼
фильтр p15-raster        (Python, от имени lp)
   │  поток команд L11: density, wakeup, enable, bitmap, gap, stop
   ▼
бэкенд p15               (Python, от имени lp)
   │  device URI p15://<MAC|имя>
   ▼
p15-leconnect (C, cap_net_raw)  → LE-соединение (HCI)
   │
BlueZ D-Bus GATT: ff02 write, ff01/ff03 notify
   │
Pristar P15
```

Почему так:

- PPD — единственный способ получить «классический» принтер в CUPS 2.4 и
  список принтеров в приложениях Mint.
- Фильтр и бэкенд разделены по конвенции CUPS: фильтр не знает про Bluetooth,
  бэкенд не знает про формат страниц. Оба можно тестировать отдельно.
- Helper с `cap_net_raw` — минимальная привилегия; демон не нужен.
- Lock-файл сериализует доступ к принтеру (CUPS может запускать job параллельно).

## Итерация 0. Проверка печати на реальном устройстве

Цель: доказать, что последовательность L11 печатает на этом экземпляре.

- [ ] `tools/p15_print_test.py`: LE-соединение, тестовая этикетка (текст + рамка).
- [ ] Пользователь подтверждает результат (печатает/не печатает).
- [ ] Зафиксировать: приходят ли кредиты CX, приходит ли результат `0xAA`.
- [ ] При необходимости скорректировать плотность/подачу/ширину.

Критерий: одна корректно напечатанная этикетка.

## Итерация 1. Ядро протокола и транспорта

- [ ] `protocol.py`: все команды, сборка bitmap-заголовка, парсер ответов.
- [ ] `image.py`: серый → FS-дизеринг → 1bpp MSB-first; порог.
- [ ] `flow.py`: отправка по 95 байт, тик 30 мс, кредиты, таймауты.
- [ ] `ble.py`: поиск GATT, StartNotify, WriteValue, ожидание ServicesResolved,
      вызов helper, Disconnect, обработка ошибок.
- [ ] Юнит-тесты без железа (protocol/image/flow на фейковом транспорте).

Критерий: `pytest` зелёный; тестовая печать через новую библиотеку.

## Итерация 2. Фильтр CUPS

- [ ] Разбор CUPS raster: `RaS2`, заголовки страниц, 1bpp и 8bpp, PIXEL_PACKED.
- [ ] Кодирование каждой страницы: density, wakeup, enable, bitmap, gap/feed, stop.
- [ ] Опции из argv[5]: `P15Density`, `P15PaperType`, `P15Dither`, `P15FeedDots`.
- [ ] Обработка `media`/`PageSize` из заголовка (ширина = реальная ширина этикетки).
- [ ] Проверка через `pdftoraster` на эталонном PDF; сравнение бинарного вывода.

Критерий: фильтр выдаёт валидный поток для 1 и нескольких страниц.

## Итерация 3. Бэкенд CUPS

- [ ] URI `p15:///<MAC>` и `p15://auto`.
- [ ] Чтение stdin, отправка через `flow.py`, аккуратный SIGTERM.
- [ ] Lock `/run/lock/pristar-p15.lock`; повтор подключения 2–3 раза.
- [ ] Коды выхода CUPS (0 — успех, 3/4 — временная/постоянная ошибка).
- [ ] Логи в stderr (видны в error_log).

Критерий: `lp -d Pristar-P15 test.pdf` печатает из CLI.

## Итерация 4. PPD и очередь

- [ ] `pristar-p15.ppd`: 203 dpi, `*cupsFilter2` на raster, размеры этикеток
      22×12, 22×14, 26×15, 30×12, 30×14, 30×15, 40×12, 40×14, 40×15, 50×15 мм.
- [ ] Опции плотности/типа ленты/дизеринга в PPD.
- [ ] `pristar-p15-setup`: поиск принтера, выбор MAC, `lpadmin -p "Pristar P15"`.
- [ ] Проверка: принтер виден в system-config-printer и в диалогах печати.

Критерий: печать из LibreOffice/Chromium/GTK-приложения.

## Итерация 5. Упаковка

- [ ] `debian/`: `pristar-p15-driver_<ver>_all.deb`.
- [ ] postinst: установка PPD, `setcap cap_net_raw+ep` на helper.
- [ ] postinst: опционально создать очередь (по ответу пользователя).
- [ ] README: установка, настройка, диагностика.
- [ ] Удаление: prerm/postrm, `lpadmin -x`, снятие очереди.

Критерий: установка на чистую систему Mint 22.3 одной командой `apt install`.

## Итерация 6. Надёжность

- [ ] Принтер спит/выключен: retry 10 с, понятная ошибка в CUPS.
- [ ] Клон не присылает `0xAA`: успех по завершении передачи + Disconnect.
- [ ] Отмена job (SIGTERM) не оставляет висящее LE-соединение.
- [ ] Несколько job подряд; повторное использование/переподключение.
- [ ] Пустая/кривая страница, очень большая страница (обрезка по ширине).
- [ ] Диагностика: `pristar-p15 status`, `--debug`.

Критерий: 20 заданий подряд без сбоев.

## Риски и меры

| Риск | Мера |
|---|---|
| BlueZ выбирает BR/EDR | helper `p15-leconnect` с `cap_net_raw` |
| Клон падает на пакетах >95 B | жёсткий лимит 95, игнорировать MTU |
| Нет уведомлений/кредитов | пейсинг 30 мс, успех без `0xAA` |
| Принтер засыпает | retry, явная ошибка, инструкция |
| `lp` без прав | helper с capability, D-Bus разрешён политикой |
| Ширина этикетки | брать из raster header, не добивать |
